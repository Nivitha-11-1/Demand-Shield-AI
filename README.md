# demand_shield_ai Flow

This project defines a declarative CrewAI Flow in `src/demand_shield_ai/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/demand_shield_ai/flow.yaml` to change the flow. Add reusable crews under `src/demand_shield_ai/crews/`, custom Python tools under `src/demand_shield_ai/tools/`, and shared knowledge files under `src/demand_shield_ai/knowledge/`.
